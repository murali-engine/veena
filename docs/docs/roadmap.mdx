# Status and roadmap

Veena is usable today, but its APIs are still evolving. The repository examples are the source of truth for current behaviour.

## Mature foundations

- Deterministic scene/timeline sampling and preview/export parity
- Landscape, portrait, and square composition
- DOM/SVG, React, and Three.js hybrid scenes
- Core shapes, paths, groups, themes, cameras, updaters, and scene views
- MP4, PNG, transparency, screenshots, GIFs, and looped audio
- Shape, text, formula, and vector LaTeX morphing
- Semantic matrices, linear algebra, tensors, neural networks, and attention views
- Reusable opening, fireworks, wave mesh, branding, subscribe, and logo components

## Areas still evolving

- Wider automatic layout and collision avoidance
- More complete language support in `CodeBlock`
- Richer asset loading and model/material workflows
- Broader mathematical and AI teaching components
- Additional output formats and media composition
- API stabilisation, performance profiling, and packaging polish

The project favours reusable semantics over one-off example code. When an example repeatedly hand-wires a visual idea, that is a signal to promote the behaviour into an appropriate tattva package.

For native or lower-level requirements beyond this implementation, see [Murali (Rust)](https://github.com/murali-engine/murali-rs/tree/main/docs).

# API areas

Veena's public API is organized into focused package subpaths:

| Area | Import path | Purpose |
| --- | --- | --- |
| Core | `veena/core` | Scenes, timelines, cameras, and deterministic state |
| Primitives | `veena/primitives` | Shapes, paths, props, and foundational geometry |
| Text | `veena/text` | Labels, 3D text, and text/formula morphing |
| Maths | `veena/maths` | Graphs, matrices, fields, surfaces, and notation |
| AI | `veena/ai` | Neural networks, tensors, attention, and model diagrams |
| Storytelling | `veena/storytelling` | Openings, stepwise stories, chat, and celebrations |
| Composite | `veena/composite` | Reusable authored components and branded elements |

Detailed API references will be added after the public interfaces stabilize.

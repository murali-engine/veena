# API areas

Veena's public API is organized into focused package subpaths:

| Area | Import path | Purpose |
| --- | --- | --- |
| Core | `veena-engine/core` | Scenes, timelines, cameras, and deterministic state |
| Primitives | `veena-engine/primitives` | Shapes, paths, props, and foundational geometry |
| Text | `veena-engine/text` | Labels, 3D text, and text/formula morphing |
| Maths | `veena-engine/maths` | Graphs, matrices, fields, surfaces, and notation |
| AI | `veena-engine/ai` | Neural networks, tensors, attention, and model diagrams |
| Storytelling | `veena-engine/storytelling` | Openings, stepwise stories, chat, and celebrations |
| Composite | `veena-engine/composite` | Reusable authored components and branded elements |

Detailed API references will be added after the public interfaces stabilize.

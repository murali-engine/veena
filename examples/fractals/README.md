# Fractal examples

Veena's line fractals are reusable `FractalPathTattva` objects, not example-only geometry.

```bash
npx tsx fractals/01-recursive-growth.ts --preview
npx tsx fractals/02-fractal-background.ts --preview
```

The first scene animates recursion depth for the three built-in generators. The second deliberately treats fractals as quiet, low-opacity background elements behind ordinary text.
